const PLAYED_AT_TOLERANCE_MS :34

Max distance between a scan's play time and a game's report for them to be the same game: headroom for a slow reporter and the client's clock, still far inside the gap between two plays of one map. Outside every candidate the scan stays unlinked (re-sendable) rather than silently putting strangers on a match page.

export const PLAYED_AT_TOLERANCE_MS = 30 * 60 * 1000;

function matchedGames :141

Decides which game result each ingested match links to.

Only matches with a known winner, two full teams and a play time qualify (minimap-only and VoD reads never link). Matches and games are walked chronologically: each match takes the unassigned game of the same mode+stage reported nearest it that the sender played on the POV seat's side, none beyond PLAYED_AT_TOLERANCE_MS.

A scan only links to a game its sender played: one without a POV seat (cast footage) or sent by someone outside the game's active rosters never does. Other lobbies, unreadable mode/stage and duplicate detections are skipped.

Matches arrive over many requests, so games already linked are skipped — unless the incoming match is a re-detection of the linked one, which lands on the same game so re-sends stay idempotent and another POV's scan joins it.

export function matchedGames({
	matches,
	games,
	povUserId,
}: {
	matches: ScannerMatch[];
	games: IngestableGame[];
	/** the sender, who is the POV player of the request's non-cast matches */
	povUserId: number | null;
}): MatchedGame[]
