sendou.ink can be translated into any language. The easiest way to contribute is the [Translate page](https://sendou.ink/translate):

1. Pick your language to see the texts that still need a translation, along with the English original and where on the site each one is used
2. Write your translation and save it as a draft. Drafts are saved in your browser, no login needed
3. Use "Preview on site" to see your drafts on the real site
4. Use "Download files" and upload them to GitHub or send them to Sendou

You can also edit the translation files directly. All of them can be found in the [locales folder](../locales):

1. Open the English `.json` file (e.g. `locales/en/common.json`) and the same file for your language (e.g. `locales/de/common.json` for German, create it if it doesn't exist)
2. Lines missing from your language's file are the ones that need translating, until then the English text is shown
3. Copy them over and translate the text while keeping the "key" on the left side of `:` unchanged. For example `"country": "Country",` could become `"country": "Maa",`
4. Send the translated .json to Sendou or make a pull request

Things to note:

- `weapons.json` and `gear.json` are auto-generated. Don't touch these.
- Español (Latino) only holds the texts that differ from Español (España), anything missing is shown in Español (España).
- If you want to add a new language, ask Sendou.
- Some lines have dynamic parts like `"articleBy": "by {{author}}"`. The `{{author}}` part should appear in the translated version unchanged - don't translate the part inside `{{}}`.
- Another special syntax: `"project": "Sendou.ink is a project by <2>Sendou</2> with help from contributors:"`. The `<2></2>` tags should appear in the translated version, but the text inside them can change.
- Some English keys come in plural variants like `"tournament_one"` and `"tournament_other"`. Languages that only have a single plural form (e.g. Chinese, Japanese, Korean) can only hold **one** translation for such a key, so during syncing these variants are collapsed into a single key (e.g. `"tournament"`). When collapsing, the `_other` value is kept (it's the one that includes the `{{count}}` number), and the other variants are discarded. This means for these languages you should translate the `_other` variant. 

## Taking drafts live

When you are done, use "Download files" on the language's page. It gives the full translation files (a zip if there are several) with your drafts written over the current translations. Upload them to GitHub to replace the files in `locales/<language>/` or send them to Sendou. Once they are live, the page forgets the drafts on its own.

Drafts only exist in the browser they were written in. To continue elsewhere (or after clearing the browser's data), use "Import files" with the downloaded files: whatever differs from the current translations becomes a draft again.

The "used on" info of each text comes from `translation-usage.json`, generated by `pnpm run i18n:usage` (run automatically by `pnpm run build` and `pnpm run dev`).

Any questions please ask Sendou!
